Kale Asynchronous File Service

Static File Demo

This static HTML page is served directly through Kale's high-performance asynchronous HTTP server.

Available Endpoints

  • GET /static/index.html — Uncached static asset handler
  • GET /cached/index.html — LRU-cached static asset handler
  • GET /download/:filename — Direct async file download with RFC 7233 Range support

Try Range Request with curl:

curl -i -H "Range: bytes=0-100" http://127.0.0.1:8080/static/index.html
